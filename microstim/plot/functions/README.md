# Functions

## GIF
Creates an animation of the field potential as a function of distance over time period N. Sends time step plots to the "results" folder.

## Radii
Creates a plot of maximum radius achieved over time.

## Maximum Potential
Creates a plot of maximum potential over distance or specific position x away from the electrode.

## Heatmaps
Creates plot of the weight/direct effect parameters for the propagation of potential. Displaying stable, unstable, amplified regions over a parametrized heatmap.
